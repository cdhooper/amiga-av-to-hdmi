# Using the Board

This document covers normal operation of the Amiga Pi to HDMI board after installation.

## Normal video operation

The normal video path is:

```text
Amiga Video Slot
      |
      v
Video Capture (CPLD)
      |
      v
Raspberry Pi (RGBtoHDMI software)
      |
      v
HDMI switch
      |
      v
Rear HDMI connector
```

Turn on the Amiga and display. The Raspberry Pi runs RGBtoHDMI and produces the HDMI video signal.

RGBtoHDMI is responsible for the actual video processing and display configuration.

See the [RGBtoHDMI documentation](https://github.com/hoglet67/RGBtoHDMI) for details on profiles, modes, scaling, and display configuration.

## FlashFloppy OSD

When the STM32F103 and FlashFloppy are configured correctly, FlashFloppy status information is displayed on the Amiga HDMI output.

Typical information includes the current disk image and FlashFloppy status.

The OSD is generated by the board's STM32F103 firmware and incorporated into the display path.

See [FlashFloppy OSD](flashfloppy_osd.md).

## Amiga keyboard control

The STM32 can provide keyboard control of FlashFloppy.

This allows the Amiga keyboard to be used for FlashFloppy functions without requiring direct access to the Gotek buttons for normal operation.

The exact key assignments depend on the board-specific FF OSD firmware configuration.

## HDMI input switching

The integrated HDMI switch allows the rear HDMI output to select between:

1. The Raspberry Pi / RGBtoHDMI output.
2. A second HDMI source connected to the board, such as Z3660.

This makes it possible to install another HDMI video source inside the Amiga and select it using the board's HDMI switching control.

The secondary HDMI connector type is revision-dependent. Rev7.2 uses a female connector. Previous versions use a male connector.

## RGBtoHDMI controls

The board's rear-facing buttons are used by RGBtoHDMI. The top button enters/selects the menu choices, and the lower two buttons move up/down in a list.

RGBtoHDMI should automatically detect that it is installed in an Amiga, and that the three buttons are available.

## Audio capture

Rev6 and later provide integrated HD Audio capture.

The audio path is merged by the Raspberry Pi with the processing video path. If you are connecting to an HDMI monitor or television, you should hear audio from your Amiga on that device. If your monitor does not support HDMI audio, you can use an HDMI audio splitter, or connect direct to the Amiga audio jacks using standard analog audio equipment.

## Secondary HDMI source

To use the secondary HDMI input:

1. Install the secondary HDMI source internally in the Amiga.
2. Connect it to the board's secondary HDMI input.
3. Power the source appropriately.
4. Select the secondary HDMI input using the board's HDMI switch control.
5. Confirm that the rear HDMI output now displays the secondary source (for testing purposes, you can install a jumper on J5 to switch).

The secondary source must produce an HDMI signal which is compatible with your display.

## What the board does not do

The board does not emulate a floppy drive itself. FlashFloppy continues to run on the Gotek.

The board does not provide an independent retargetable graphics display, such as what is provided by the PicassoIV or ZZ9000.

The board does not provide full 24-bit AGA video capture on the A4000. A4000 operation is limited to 12-bit video. All Amiga models are limited to OCS resolution screen modes.

## Recommended operating practice

For reliable operation:

- Use a known-good Raspberry Pi.
- Use a reliable microSD card.
- Use a current RGBtoHDMI software release.
- Use a current [FlashFloppy](https://github.com/cdhooper/flashfloppy-osd-avhdmi/releases) release.
- Use the board-specific FF OSD firmware.
